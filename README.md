# 🌾 STAR-D

STAR-D (Smart Techniques for Agriculture & Rural Development) is a full-stack agricultural intelligence platform designed to support farmers with data-driven insights for smarter crop planning and decision-making.

##  Features
- Crop recommendations
- Market price analysis
- Pest risk prediction
- Government scheme guidance
- Profit estimation
- Multilingual support (English, Kannada, Hindi)
- Responsive UI with PWA support

##  Tech Stack
- Frontend: Next.js, Tailwind CSS, Zustand
- Backend: Node.js, Express, MongoDB
- ML-ready architecture (mock predictions)

## ⚠️ Note
This project currently uses mock data and placeholder ML models. Authentication and deployment are planned as future enhancements.
