# Smart Farm Hub - Frontend

Next.js React app for Smart Farm Profit Maximization Hub.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Features

- 🌾 Crop profit recommendations
- 📊 Interactive comparisons
- 🎯 What-if simulations
- 🏛️ Government schemes
- 📈 Market price predictions
- 🗺️ Pest outbreak maps
- 💰 Input cost optimization
- 💧 Irrigation scheduling
- 🌤️ Climate risk alerts
- 📚 Learning hub
- 💬 AI chat advisor
- 🌐 Multi-language (Kannada, Hindi, English)
- 📱 Offline-first support

## Project Structure

```
src/
├── app/                    # Next.js app router
├── components/             # Reusable React components
├── lib/
│   ├── api.ts             # API service
│   └── utils.ts           # Utility functions
├── hooks/                  # Custom React hooks
├── types/                  # TypeScript types
└── i18n/                   # Translations
```
