## 🚀 TO GO LIVE (3 Simple Steps)

### **Step 1: Push to GitHub** (5 minutes)
```bash
git init
git add .
git commit -m "Smart Farm Hub MVP - Ready for deployment"
git remote add origin https://github.com/YOUR_USERNAME/smart-farm-hub
git push -u origin main
```

### **Step 2: Deploy Frontend** (10 minutes)

**Via Vercel Dashboard:**
1. Go to vercel.com
2. Sign in with GitHub
3. Click "New Project"
4. Import: smart-farm-hub repository
5. Root directory: frontend
6. Click "Deploy"
7. Wait 1-2 minutes

**Get URL:** https://smart-farm-hub.vercel.app (or your custom domain)

### **Step 3: Deploy Backend** (10 minutes)

**Via Railway Dashboard:**
1. Go to railway.app
2. Sign in with GitHub
3. Click "New Project"
4. Create from GitHub: smart-farm-hub
5. Railway auto-detects backend (railway.json)
6. Add environment variables:
   - MONGODB_URI: (from MongoDB Atlas)
   - JWT_SECRET: (random string)
   - NODE_ENV: production
7. Click "Deploy"
8. Wait 1-2 minutes

**Get URL:** https://smart-farm-api-xxxxx.railway.app

## 📞 QUICK REFERENCE

### **Local Development**
```bash
# Setup
npm install                    # All dependencies
npm run build                  # Build both

# Frontend
cd frontend && npm run dev     # http://localhost:3000

# Backend
cd backend && npm run dev      # http://localhost:5000

# Together
npm run dev                    # Both in parallel
```

### **Deployment**
```bash
# Push to GitHub
git push origin main           # Triggers auto-deploy

# Or manual
vercel --prod                  # Deploy frontend
# Railway deploys automatically from GitHub
```

### **Troubleshooting**
```bash
# Frontend won't build?
cd frontend && npm install     # Reinstall deps
npm run lint                   # Check for errors
rm -rf .next && npm run build  # Clean rebuild

# Backend won't start?
cd backend && npm install      # Reinstall deps
npm run build                  # Compile TypeScript
npm start                      # Run

# API not connecting?
Check MONGODB_URI in .env
Check API_URL in frontend .env
Check CORS_ORIGIN in backend .env
```
