## 🚀 GO LIVE IN 30 MINUTES

**3 Simple Steps:**

### **Step 1: Push to GitHub** (5 min)
```bash
git init
git add .
git commit -m "Smart Farm Hub MVP - Production Ready"
git remote add origin https://github.com/YOUR_USERNAME/smart-farm-hub
git push -u origin main
```

### **Step 2: Deploy Frontend** (10 min)
```
1. Go to vercel.com
2. Sign in with GitHub
3. Create new project → Select smart-farm-hub
4. Select frontend folder
5. Click Deploy
→ LIVE at: https://smart-farm-hub.vercel.app
```

### **Step 3: Deploy Backend** (10 min)
```
1. Go to railway.app
2. Create project → Connect GitHub smart-farm-hub
3. Add environment variables:
   - MONGODB_URI (from MongoDB Atlas)
   - JWT_SECRET (generate random)
   - NODE_ENV: production
4. Click Deploy
→ LIVE at: https://smart-farm-api-xxx.railway.app
```
